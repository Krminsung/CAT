# [cat][P03] provider와 streaming transport

## 범위

Responses와 OpenAI Chat 호환 API를 공통 provider event로 변환한다. 인증된 모델
transport의 HTTP/SSE, adapter 두 종류, 13개 provider catalog와 capability를
구현한다. 원본 `src/api.ts`, `src/providers.ts`, `src/http.ts`, `src/errors.ts`와
관련 provider/API 테스트의 계약만 읽었으며 실행하지 않았다.
