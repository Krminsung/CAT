# P14.R13 — 모델 주도 하네스 실행 흐름 복원

## 승인과 기준

2026-09-29 사용자가 개별 날씨 예외가 아닌 하네스 기능 동등성 방향의 보완을 승인했다.
시작 HEAD는 `2bd247a16abaa899526a89aab80592ae40f6841a`이며 미배포 R12 변경을 보존한다.
main 기준은 `8a3bc407d64271b9640f2161b2da4e0aaf8288a5`이다.
기존 build/runtime 예산은 재개하거나 초기화하지 않는다. 이번 작업은 소스 수정·읽기·로컬 커밋만
수행하며 build/check/test/앱·모델 API·서버 실행/포장/원격 게시를 포함하지 않는다.

직접 읽는 기능 기준은 제공된 Smile Code TypeScript 0.14.6의 `src/agent.ts`, `src/tools.ts`와
관련 모듈이다. Claude Code 고정 참조 `6f6f12b37f529488b10e53928dd5508bb93535c7`과의 관계는
원본 `docs/python-harness-parity.md` 및 기존 Python `docs/harness-reference-review.md`의
기록을 참고한다. 그 과거 검토·테스트를 이번의 직접 검토·실행 결과로 주장하지 않는다.
참조 코드·프롬프트·자산을 복제하거나 dependency에 넣지 않고 관찰 가능한 계약을 독립 구현한다.
현재 공식 Claude Code 전체와의 동등성을 인증하는 작업이 아니다.

### 기준선 밖과 남은 확인

기존 이관 기준에서 Anthropic 계정/OAuth·구독, claude.ai 원격 세션, vendor telemetry,
marketplace, 음성·브라우저·Windows 전용 계층은 제외됐다. 제품 내부 다중 agent·daemon도 현재
계약에 없다. 해당 기능이 CAT에서 된다고 표시하지 않으며, 최신 공식 제품의 모든 기능까지
지원한다고 확대 해석하지 않는다. 정확한 동등성 판정에는 동일한 사용자 시나리오의 실행 비교가
필요하다. 모델의 추론 품질과 공급자별 API 기능 차이도 하네스 소스만으로 보장하지 않는다.
