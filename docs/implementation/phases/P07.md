# [cat][P07] TUI core

## 범위

pi-tui alternate screen에 header, transcript, multiline editor와 status 영역을 분리하고,
Unicode 입력·단축키·stream/tool/plan 갱신·native selection·raw transcript 흐름을 연결한다.
원본 `src/tui.ts`와 `src/clipboard.ts`, 설치된 pi-tui 0.85.1의 타입과 구현 계약만 읽으며
원본 TUI나 테스트를 실행하지 않는다. CLI 조립과 slash command dispatch는 P08,
SSH/OSC52 bridge는 P12 범위로 남긴다.

P06은 PR #6의 head `5a0b32ed50faf6d32cd064052999039e71d44135`를 merge commit
`c434311e79ac2c112ea8ac08e31b5a320dff3e2f`로 병합했고 tree·부모·`origin/main`
정합성을 확인했다. 이 커밋이 P07의 기준 main이다.

## P07.1 구현 메모

- stdin과 stdout의 TTY 여부를 시작 전에 각각 검사한다. stderr 상태는 독립적으로 노출하고 진단은
  stdout 화면과 섞지 않는 plain stderr writer로 보낸다. 비TTY에서는 raw mode나 alternate screen을
  시작하지 않는다.
- pi-tui의 terminal resize callback과 명시적인 terminal-height `VStack`을 사용해 header 1행,
  follow-end transcript, 가변 multiline editor, status 1행을 분리한다. editor만 focus를 소유하고
  실제 입력·stream 도중 cursor 및 scroll 세부 계약은 다음 하위 작업에서 연결한다.
- 모든 표시 문자열과 구성 요소 출력은 byte·행·표시 폭을 제한하고 외부 ANSI/OSC/APC와 제어 문자를
  제거한다. editor의 pi-tui cursor marker만 한 개의 내부 표시 제어로 보존하며 mouse reporting과
  자동 selection copy는 시작부터 끈다.
- 시작 일부 실패, component render/input/mouse/invalidate 실패와 애플리케이션 예외는 최초 오류만
  보존하고 새 run을 만들지 않는다. 정상·오류 종료 모두 `preserveScreen`을 사용하며 raw mode,
  bracketed paste, mouse, autowrap, cursor, alternate-screen 복원을 멱등 경계에서 수행한다.
- 초기 transcript API도 항목·개별 byte·합계 byte·render row가 제한되어 있다. token/tool/plan별로
  전체 기록을 다시 조합하지 않는 증분 상태는 P07.3에서 이 경계 위에 구현한다.

## P07.2 구현 메모

- pi-tui Editor의 `Intl.Segmenter` 기반 grapheme 이동과 `visibleWidth` 기반 한글·전각·결합문자·emoji
  배치를 유지한다. cat의 `BoundedEditor`는 전체 입력 512KiB, 단일 비-paste event 64KiB로 제한하며
  외부에서 설정하는 문자열도 UTF-8 경계에서 자른다.
- Enter는 Editor의 submit, Ctrl+J와 Shift+Enter는 newline 경로를 그대로 사용한다. bracketed paste는
  ANSI/제어 문자를 제거하고 하나의 제한된 paste event로만 편집기에 전달하므로 포함된 줄바꿈이나
  명령 모양 텍스트가 자동 submit 또는 dispatch를 만들지 않는다.
- controller가 submit Promise의 수명 동안 editor submit과 다른 키 입력을 막는다. busy Ctrl+C는
  cancellation callback을 한 번만 호출하고, idle Ctrl+C는 입력만 지우며, 빈 idle Ctrl+D만 화면을
  닫는다. Shift+Tab/Alt+M, Ctrl+O, Ctrl+P는 각각 실제 permission owner와 details/session callback에
  연결되는 명시적 port다.
- 일반 prompt history는 연속 중복을 제거하고 100개·256KiB 안에서만 pi-tui Editor에 추가한다.
  masked secret overlay는 별도 component와 callback만 사용하며 값을 getter, 일반 history, transcript,
  clipboard에 제공하지 않는다. Enter 전에 8–8192 bytes를 확인하고 완료 즉시 입력값을 비운다.
- 새 secret은 화면 redactor에 제한된 수명으로 등록한다. overlay 취소·abort·화면 종료는 listener,
  focus와 callback을 정리하며 화면 종료 뒤 동적으로 추가한 secret 목록도 폐기한다.

## P07.3 구현 메모

- transcript는 항목별 pi-tui component와 ID map을 유지한다. text delta는 현재 assistant 항목만,
  tool start/result와 plan update는 같은 ID component만 갱신하며 완료된 항목의 render cache를
  다시 만들지 않는다.
- assistant stream, 정적 text, tool detail, plan step과 notice 각각에 byte 상한을 두고 전체 상태도
  512개 항목·4MiB로 제한한다. 오래된 비활성 항목을 먼저 제거하고 active 항목도 전체 한도를 넘겨
  무제한 누적하지 않는다. run sequence와 restore record 수도 별도로 제한한다.
- tool 결과는 success/failure/denied/cancelled 상태를 같은 행에 반영하고 detail은 기본 접힘 상태로
  둔다. plan은 하나의 현재 상태 component로 유지하며 전체 또는 개별 tool의 펼침 상태만 바꾼다.
- transcript 변경 시 `ScrollView`의 follow 상태를 강제로 바꾸지 않는다. 사용자가 끝에 있을 때만
  pi-tui가 새 출력에 따라가고, 위로 이동한 동안에는 현재 scroll 위치를 유지한다.
- resume은 저장 record를 bounded decoder로 다시 읽어 user/assistant/tool 표시로 투영하고 복원 제한과
  손상 record를 notice로 남긴다. raw snapshot도 이미 redaction·escape 제거를 거친 제한된 표시값만
  내보내며 실제 `/raw` 화면 전환은 P07.4에서 연결한다.

## 상태

P07.3 구현 중이다. 단계 검증은 아직 실행하지 않았고 실제 terminal stream, scroll 또는 resume 화면을
실행하지 않았다.
