# [cat][P08] CLI·slash 명령·overlay

## 범위

실제 `cat-tui` entrypoint에서 argv, 비대화형 출력, 단일 slash command registry, 선택·승인
overlay와 세션→trust→context→run→저장→종료 lifecycle을 연결한다. 원본
`src/cli.ts`, `src/tui.ts`, `src/auth.ts`의 해당 계약만 읽고 원본 앱·API·테스트는 실행하지 않는다.
AGENTS·skills·markdown command·hooks는 P09, MCP는 P10, background·worktree·SSH는 P12에 남긴다.

P07은 검토 head `2f7df0ef1fb1b02277a16c9df537722104206070`을 PR #7에서 merge commit
`4d91f4a4716831a488c3ebb4ed0d94e95cc06070`으로 병합했다. merge의 두 부모, tree,
phase head 조상 관계와 `origin/main` 포함을 확인했으며 병합 뒤 검사는 실행하지 않았다.

## P08.1 구현 메모

- 옵션 이름, 값, 중복, 크기와 enum을 제한하고 `--continue`/`--resume`, 구조화 출력/print,
  worktree/session 충돌을 사용법 오류로 구분한다. 알 수 없는 옵션을 prompt로 삼지 않는다.
- text 결과와 진단은 각각 stdout/stderr로 분리하고 JSON/stream JSON은 ANSI를 실행하지 않는
  한 줄 JSON record만 stdout에 쓴다. 구조·record·text 크기와 redaction 경계를 둔다.
- help/version과 관리 명령은 TUI를 만들지 않는 entrypoint 경로를 사용한다. 아직 P08.4에서
  연결하지 않은 agent lifecycle은 빈 성공 대신 명시적 오류를 반환한다.

## 상태

P08.1을 구현하고 정적 소스 검토 중이다. 자동 검증, 앱, TUI, provider, 도구는 실행하지 않았다.
